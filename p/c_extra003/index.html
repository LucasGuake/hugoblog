第一章 介绍

在<C语言学习DLC_指针及延申>的函数的形参实参与指针传参中我们已经为本文留下了悬念。

对于函数传参有两种方式，下面我们来一一介绍。

Note

对于返回值和指针这里仅做介绍以供下文铺垫，我们不会过多赘述细节。初学者建议学习后再继续阅读。

返回值

这是非常容易理解的一种写法。我们学习函数就已经知道，函数传参是有实参形参之分，改变形参不会影响实参。所以我们就手动把形参赋值给实参。

#include <stdio.h>

// 函数返回值写法：通过return返回结果
int add_return(int a, int b) {
    return a + b;  // 直接返回计算结果
}

int main() {
    int x = 5, y = 3;
    int result = add_return(x, y);  // 接收返回值
    
    printf("函数返回值写法: %d + %d = %d\n", x, y, result);
    return 0;
}

指针

根据指针的特性：它指向一个地址。我们可以把地址给函数，让函数改变地址处代表的值，这样就不在需要返回。这种方法更常用。

#include <stdio.h>

// 指针参数写法：通过指针参数"返回"结果
void add_pointer(int a, int b, int *result) {
    *result = a + b;  // 将结果存入指针指向的内存
}

int main() {
    int x = 5, y = 3;
    int result;
    
    add_pointer(x, y, &result);  // 传递result的地址
    
    printf("指针参数写法: %d + %d = %d\n", x, y, result);
    return 0;
}

第二章 引申

类似前文。存在返回值和指针两种方法。那末就存在一级指针+返回值和二级指针两种方法了。

这两类写法主要在数据结构的链表等方面有很多作用。

先介绍带头节点的写法

在数据结构中，我们一般用以下代码来创建一个结构体

1
2
3

typedef struct ListNode {
    int data;
    struct ListNode* next;
} Node;

我们可以把这个结构体看成一个大括号。{data，*next}; 我们需要指针指向这个大括号。而*next用来指向下一个结构体单元。

我们想写一个函数来实现这个指向效果，就需要传参了。

我们初学时是这么写的，这里以链表头插法为例。

ListNode* head 表示 head 是一个指向 ListNode 结构体的指针。我们一开始就初始化了头节点，并保持头节点固定，只要插入数即可。

这种方法在老师讲课时让我们很容易就懂得链表头插法的原理。

一级指针+返回值

原理：创建新节点，指向旧头，返回新头 (新节点当头，指向旧头，返回新头。每次插入都要更新头指针。)

由于需要返回，我们就把函数类型设定为Node*

结构体不变，其余代码如下：

// 在链表头部插入节点
Node* insertAtHead(Node* head, int value) {
    Node* newNode = (Node*)malloc(sizeof(Node));
    newNode->data = value;
    newNode->next = head;
    return newNode;  // 返回新的头节点
}

// 使用方式
int main() {
    Node* head = NULL;
    head = insertAtHead(head, 10);  // 必须接收返回值
    head = insertAtHead(head, 20);
    ...
}

其逻辑如下：

链表 命令
head = NULL Node* head = NULL;
(newNode)[10]→NULL insertAtHead(head, 10);
(head)[10]→NULL 第一步完 head = insertAtHead(head, 10);
(newNode)[20] → (head)[10]→NULL insertAtHead(head, 20);
(head)[20] → [10]→NULL 第二步完 head = insertAtHead(head, 20);

我们发现，它的head在不断赋值改变。它的头节点并不固定。

原理：通过二级指针直接修改外部的一级指针

// 二级指针头插法
void insertAtHead(Node** headPtr, int value) {
    // 1. 创建新节点
    Node* newNode = (Node*)malloc(sizeof(Node));
    newNode->data = value;
    
    // 2. 新节点指向当前头节点
    newNode->next = *headPtr;
    
    // 3. 通过二级指针修改外部头指针
    *headPtr = newNode;
}

int main() {
    Node* head = NULL;           // ① head = NULL
    
    insertAtHead(&head, 10);     // ② 传入head的地址
    // 在insertAtHead函数中：
    // headPtr = &head
    // *headPtr = head (即NULL)
    // *headPtr = newNode (修改了head的值)
    
    insertAtHead(&head, 20);     // ③ 再次修改head
}

我们对此进行简单的分析：

步骤1: (newNode) [10]→NULL 步骤2: *headPtr = newNode (head从NULL变成指向newNode)

结果： (head) [10]→NULL

插入前： (head) [10]→NULL

步骤1: (newNode) [20]→ NULL 步骤2: (newNode )[20| → (head)[10]→ NULL (指向*headPtr即原head) 步骤3: *headPtr = newNode (head指向新节点)

结果： (head)[20| → [10]→ NULL

我们发现，二级指针和一级指针+返回值的方法逻辑十分相似，只不过由于方法不同，写法有些许差异。

总结

我们将它们总结如下表

特性 一级指针 + 返回值 二级指针 带头节点
头指针处理 需要返回新头 直接修改 头节点固定不变
空链表判断 head == NULL head == NULL head->next == NULL
插入头 需要特殊处理 需要特殊处理 统一处理
删除头 需要特殊处理 需要特殊处理 统一处理
函数参数 func(head, ...) func(&head, ...) func(head, ...)
返回值 必须返回新头 void 通常返回状态
适用场景 简单应用 专业代码 教学、简单应用

TreeNode* insertBST(TreeNode* root, int val) {
    if (root == NULL) {
        TreeNode* node = (TreeNode*)malloc(sizeof(TreeNode));
        node->val = val;
        node->left = node->right = NULL;
        return node;
    }
    
    if (val < root->val) {
        root->left = insertBST(root->left, val);
    } else {
        root->right = insertBST(root->right, val);
    }
    
    return root;
}

// 使用
TreeNode* root = NULL;
root = insertBST(root, 5);
root = insertBST(root, 3);
root = insertBST(root, 7);

void insertBST2(TreeNode** rootPtr, int val) {
    if (*rootPtr == NULL) {
        TreeNode* node = (TreeNode*)malloc(sizeof(TreeNode));
        node->val = val;
        node->left = node->right = NULL;
        *rootPtr = node;
        return;
    }
    
    TreeNode* current = *rootPtr;
    while (1) {
        if (val < current->val) {
            if (current->left == NULL) {
                current->left = (TreeNode*)malloc(sizeof(TreeNode));
                current->left->val = val;
                current->left->left = current->left->right = NULL;
                break;
            }
            current = current->left;
        } else {
            if (current->right == NULL) {
                current->right = (TreeNode*)malloc(sizeof(TreeNode));
                current->right->val = val;
                current->right->left = current->right->right = NULL;
                break;
            }
            current = current->right;
        }
    }
}

// 使用
TreeNode* root = NULL;
insertBST2(&root, 5);
insertBST2(&root, 3);
insertBST2(&root, 7);

int insertBST3(TreeNode* root, int val) {
    // 无法创建新树，只能插入到已有树中
    if (root == NULL) return -1;  // 失败
    
    TreeNode* parent = NULL;
    TreeNode* current = root;
    
    while (current != NULL) {
        parent = current;
        if (val < current->val) {
            current = current->left;
        } else if (val > current->val) {
            current = current->right;
        } else {
            return 0;  // 值已存在
        }
    }
    
    TreeNode* node = (TreeNode*)malloc(sizeof(TreeNode));
    node->val = val;
    node->left = node->right = NULL;
    
    if (val < parent->val) {
        parent->left = node;
    } else {
        parent->right = node;
    }
    
    return 1;  // 成功
}

// 使用
TreeNode* root = (TreeNode*)malloc(sizeof(TreeNode));
root->val = 5;
root->left = root->right = NULL;

insertBST3(root, 3);  // 插入到已有树中
insertBST3(root, 7);

总结

在学习时，固定头节点方法能够帮助我们理解。

但是特别是在二叉树需要递归写法的时候，一级指针+返回值写法更为简洁易懂。当然在某种情况下，二级指针法也能发挥其作用。这要依据情况定论。

当然我们也能像指针一样研究处二级指针+返回值和三级指针等应用，只不过它可能会很绕，但逻辑类似。
